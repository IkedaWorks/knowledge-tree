# Teoria dos Conjuntos

> "Ninguém nos expulsará do paraíso que Cantor criou."  
> — **David Hilbert**

A **Teoria dos Conjuntos** é a pedra angular da matemática moderna, fornecendo a linguagem formal e a estrutura sobre a qual todas as outras ramificações, da álgebra ao cálculo, são construídas. 

Este módulo abrange desde a lógica proposicional e a axiomatização de Zermelo-Fraenkel até operações com conjuntos, produtos cartesianos e teoria das relações.
