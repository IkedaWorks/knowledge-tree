# Equações Diferenciais Ordinárias

> "As leis da natureza não são senão os pensamentos matemáticos de Deus traduzidos em equações diferenciais."  
> — **Paul Dirac**

O módulo de **Equações Diferenciais Ordinárias (EDO)** aborda o estudo de equações que relacionam uma função desconhecida de uma única variável às suas derivadas, constituindo a ferramenta fundamental para modelar sistemas dinâmicos e variações contínuas na física, engenharia e economia.

Neste módulo são analisados os conceitos fundamentais de EDOs, classificações por ordem e linearidade, soluções gerais e particulares, além de problemas de valor inicial.
