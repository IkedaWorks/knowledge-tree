
# Estatística e Probabilidade

A estatística descritiva e a teoria das probabilidades fornecem as ferramentas matemáticas necessárias para extrair informações úteis a partir de conjuntos de dados, analisar incertezas e modelar fenômenos aleatórios — habilidades fundamentais para a engenharia de computação e o desenvolvimento de algoritmos inteligentes.

## 📌 Pré-requisitos

Para um bom aproveitamento deste módulo, é recomendável ter familiaridade com:
* **Matemática Básica:** Álgebra elementar, somatórios ( $\sum$ ) e teoria dos conjuntos.
* **Cálculo I:** Conceitos básicos de funções e limites (útil para entender distribuições contínuas mais adiante).

---

## 🗺️ Roteiro de Aprendizado 

Este módulo foi estruturado para seguir uma linha lógica de aprendizado, partindo da análise de dados puros até a modelagem probabilística:

1. **Estatística Descritiva (Fase Atual):** Compreender o comportamento dos dados coletados através de medidas de centralidade e dispersão.
2. **Teoria das Probabilidades:** Estudar as chances de ocorrência de eventos e variáveis aleatórias.
3. **Distribuições de Probabilidade:** Modelar fenômenos reais utilizando distribuições discretas (Binomial, Poisson) e contínuas (Normal/Gaussiana).
4. **Inferência Estatística:** Aprender a tomar decisões e extrair conclusões sobre uma população a partir de uma amostra.
