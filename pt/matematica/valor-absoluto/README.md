# Valor Absoluto

> "A menor distância entre dois pontos no espaço real é a magnitude de sua variação."  
> — **Augustin-Louis Cauchy**

O módulo de **Valor Absoluto** explora a interpretação geométrica e algébrica da distância de um número até a origem na reta real. A compreensão do valor absoluto é essencial para o estudo avançado de métricas, limites e análise matemática.

Neste módulo são analisadas as definições fundamentais, propriedades algébricas, resolução de equações e inequações modulares, além do comportamento gráfico das funções modulares.
