# Cálculo Multivariável

> "O estudo das funções de várias variáveis é o portal de entrada para a modelagem do espaço tridimensional e do campo físico."  
> — **Joseph-Louis Lagrange**

O módulo de **Cálculo Multivariável** estende as ferramentas fundamentais do cálculo infinitesimal para funções de duas ou mais variáveis independentes, permitindo a análise de superfícies, superfícies de nível, campos escalares e vetoriais.

Neste módulo são analisadas funções de várias variáveis, limites e continuidade no espaço n-dimensional, derivadas parciais, gradientes, otimização e integrais múltiplas.
