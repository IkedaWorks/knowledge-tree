# Eletromagnetismo

> "A teoria da relatividade restrita deve sua origem às equações de Maxwell do campo eletromagnético."
> — Albert Einstein

O **Eletromagnetismo** é a teoria unificada que descreve as interações elétricas e magnéticas. Este módulo aborda desde os princípios da eletrostática e distribuições contínuas de carga até o potencial elétrico, dielétricos e o início do estudo do campo magnético.
