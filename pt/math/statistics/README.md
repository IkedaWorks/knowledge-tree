# Estatística

> "Há três tipos de mentiras: mentiras, mentiras deslavadas e estatística."  
> — **Benjamin Disraeli**

O módulo de **Estatística** fornece metodologias fundamentais para recolher, organizar, analisar e interpretar dados quantitativos. Estabelece a ponte entre conceitos matemáticos abstratos e a tomada de decisões baseada em dados sob incerteza.

Este módulo abrange a estatística descritiva fundamental, incluindo medidas de tendência central, análise de variabilidade/dispersão e propagação de incerteza de medição nas ciências empíricas.
